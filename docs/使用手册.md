# 使用手册

> 面向第一次装机的人。每一步都写清「在做什么、失败会怎样、怎么退回」。

---

## 0. 开始之前

**必须准备**
- 一台 Windows 10/11 电脑（用来制作启动盘）
- 一个 **≥8GB 的闲置 U 盘**（内容会被清空；想以后能放完整安装包就上 16GB）
- 目标机器能进 BIOS（知道 F2/F10/F9 是哪个键）
- 目标机器最终要连的 **Wi-Fi 名称和密码**（可选，但强烈建议）

**必须接受**
- 单系统会**抹掉整块硬盘**，包括原来的 Windows 和所有数据
- Intel 网卡方案下，隔空投送 / 接力 / 定位 / 自动时区 一定不可用
- 系统更新不能走 OTA

---

## 1. 跑向导

```powershell
python -m macplan
```

或者双击 `MacPlan.exe`。六步依次是：

### 第 1 步 · 选择 U 盘

工具会列出所有 **USB 总线**的磁盘（不会列出你的系统盘）。

```
1. 磁盘2 Kingston DataTraveler 7.5GB F: FAT32
```

选编号即可。三种情况：

| 情况 | 工具行为 |
|---|---|
| 容量 < 7.4GiB | 直接拒绝，换盘 |
| 不是 FAT32 | 提示你格式化，需要输入大写的 `YES` 才执行 |
| 没有盘符 | 让你先去磁盘管理分配盘符 |

> ⚠️ 格式化是不可逆的。工具只对 USB 总线、非系统盘动手，且必须手动输入 `YES`。

### 第 2 步 · Wi-Fi（可选）

读取本机保存过的 Wi-Fi 配置，把 SSID + 密码写进 `itlwm.kext`。

- **好处**：恢复环境一进去就能联网，不用插网线
- **代价**：密码是明文，EFI 在 FAT32 上任何人拿到 U 盘都能读

不想承担就选 `n`，装的时候插网线。

### 第 3 步 · 硬件扫描

优先调用 Hardware-Sniffer（和 OpCore-Simplify 同源，输出 `Report.json` + ACPI 表）；
下载失败时退回 WMI 采集（能判定，但生成 EFI 需要 Report.json）。

### 第 4 步 · 结论

输出形如：

```
✅ 结论：supported
   推荐系统：macOS Ventura（13）
   SMBIOS：MacBookPro15,2    恢复镜像 board-id：Mac-4B682C642B45593E
   依据：
     · Kaby Lake-R / Coffee Lake：Ventura 稳，Sonoma 可试
     · 检测到 Intel 核显：走 iGPU 驱动
   风险 / 不可用功能：
     · Intel 网卡无 AWDL：隔空投送 / 接力 / 定位 全部不可用
```

如果是 ❌，**停下来**。继续只会浪费时间。

### 第 5 步 · 生成 EFI + 下载镜像

- EFI：驱动 OpCore-Simplify 自动应答，产出到 `Results/EFI`
- 自动打四个补丁：`DmgLoading=Any`、`SecureBootModel=Disabled`、`ScanPolicy=0`、`LauncherOption=Bootstrap`
- 镜像：macrecovery 按版本对应的 board-id 下载，落在 `macrecovery/com.apple.recovery.boot`

### 第 6 步 · 写入 + 校验

写入 `EFI/`、`com.apple.recovery.boot/`、`使用说明.txt`，然后：
1. 逐文件 SHA256 比对
2. `BaseSystem.dmg` 的 `koly` 魔数 + 体积下限
3. `EFI/OC/OpenCore.efi` 体积、`BOOTx64.efi` 不能是 Windows 启动器

任何一项不过 → 重新写，不要带着可疑的盘去装。

## 2. 目标机器：BIOS 设置

开机按 F2（HP 是 F10）进 BIOS：

| 项目 | 设成 |
|---|---|
| Boot Mode | UEFI（不要 Legacy/CSM） |
| Secure Boot | Disabled |
| Fast Boot | Disabled |
| Virtualization (VT-x) | Enabled |
| VT-d | 可留（配 `DisableIoMapper=true`） |
| DVMT Pre-allocated | ≥64MB（核显机器） |
| CFG Lock | 能关就关，关不掉配 `AppleXcpmCfgLock=true` |

保存重启，连按 **F9** 选 U 盘。

---

## 3. 引导菜单

1. 看到 OpenCore 菜单后，**按空格**展开隐藏项
2. 找到 macOS 项（可能是橙色齿轮 + `___U___(dmg)`，这是中文卷标没有字形导致的）
3. 回车进入恢复环境

> 只有 Windows、没有 macOS 项？先检查 `DmgLoading / ScanPolicy / SecureBootModel`，
> 再看 U 盘卷标是不是纯 ASCII。详见 `docs/踩坑清单.md` 的 B06~B08。

---

## 4. 安装

1. 进恢复环境后，先用顶部菜单的**磁盘工具**
2. 显示所有设备 → 选中**整块硬盘**（不是分区）→ 抹掉
   - 名称：`Macintosh HD`
   - 格式：**APFS**
   - 方案：**GUID 分区图**
3. 关掉磁盘工具 → 重新安装 macOS → 选刚抹的盘
4. 中途会重启 2~3 次，**每次都从 OpenCore 菜单选同一个安装项**，U 盘别拔
5. 进入设置向导时先**不要**登录 iCloud（等确认硬件都正常再登）

---

## 5. 装完第一件事：把 EFI 搬进硬盘

```bash
# 1. 找到硬盘的 EFI 分区
diskutil list

# 2. 挂载（通常是 disk0s1）
sudo diskutil mount disk0s1

# 3. 备份原有内容
sudo cp -R /Volumes/EFI /Users/$(whoami)/Desktop/EFI-backup

# 4. 清掉旧 Windows 残留，拷入 U 盘的 EFI
sudo rm -rf /Volumes/EFI/EFI/Microsoft /Volumes/EFI/EFI/Boot
sudo cp -R /Volumes/<U盘>/EFI /Volumes/EFI/

# 5. 验证
ls /Volumes/EFI/EFI/OC/OpenCore.efi     # 应该有，约 600KB
```

然后拔掉 U 盘重启。**能自己进系统，才算装完。**

## 6. 装完体检

```bash
bash scripts/macos_doctor.sh
```

它会逐项检查：ESP 里的 OpenCore、`LauncherOption`、`layout-id`、USB 端口映射、
蓝牙 kext 顺序、`pmset`、时区。标 `!` 的逐条处理，处理完再跑一次。

## 7. 常见失败与回退

| 现象 | 最可能原因 | 回退动作 |
|---|---|---|
| 菜单里只有 Windows | `ScanPolicy` / `DmgLoading` / 卷标非 ASCII | 改 config，重写 U 盘 |
| 选安装项后黑屏重启 | iGPU 的 `ig-platform-id` 不对 | 换 `0x59160000` 等候选逐个试 |
| 安装到一半报镜像损坏 | 写入不完整 | 重写并看校验结果 |
| 装完拔 U 盘进不去 | ESP 里没有 `EFI/OC/OpenCore.efi` | 按第 5 节重做 |
| 装完没声音 | layout 选错 | 逐个试 24 / 28 / 1 / 23 |
| 触控板不动 | kext 类名冲突 | 只保留 PS2 链路 |
| 睡醒后蓝牙崩 | BTPatcher 版本 / 睡眠参数 | 升级 + `pmset` 修正 + 冷启动 |

**永远留一张能启动的 U 盘。** 它是唯一的救命盘。

## 8. 分步命令（排障用）

```powershell
python -m macplan scan                       # 只扫描
python -m macplan recommend                  # 只判定
python -m macplan efi --version 13           # 只生成 EFI
python -m macplan usb --drive F:             # 只写盘
python -m macplan verify --drive F:          # 只校验
```

中间产物都在仓库目录下：`SysReport/`、`Results/EFI/`、`macrecovery/`、`logs/macplan.log`。
出问题先看 `logs/macplan.log`。
