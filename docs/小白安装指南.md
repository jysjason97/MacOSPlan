# 小白安装指南

> 这份文档假设你**没装过黑苹果**，也没用过命令行。照着顺序做，遇到卡住的地方直接跳到对应小节。
>
> 先看下面三句话，能接受再往下走。

1. **单系统会抹掉整块硬盘**，原来的 Windows 和文件都会没。有要留的东西先拷到移动硬盘。
2. **不是所有电脑都能装**。MacPlan 会先告诉你结论，说"不建议"就别硬上。
3. **装完一定有几个功能用不了**（Intel 网卡尤其明显：隔空投送、定位、自动时区都没有）。这是硬件决定的，不是装错了。

---

## 先确认你走哪条路线

MacPlan 跑完会给三种结论之一，对应两条完全不同的路：

| 结论 | 走什么 | 典型机器 |
|---|---|---|
| ✅ 可用 / ⚠️ 勉强可用 | **OpenCore**（本指南第一~三阶段） | 有 Intel 核显，或有受支持的 AMD 独显 |
| 🧭 可走 Stela | **Stela**（另一套流程，见下） | 新平台，或只有 NVIDIA GTX 16 / RTX 20-50 |
| ❌ 不建议 | 放弃 | 图形不可驱动（比如只有 AMD 独显的新平台） |

### Stela 路线（实验性，先读完再决定）

Stela 不装原生 x86 macOS，而是把 **arm64 macOS 翻译成 x86-64 执行**，自己模拟成一台 M2 Mac mini。
它**只认 NVIDIA GTX 16 / RTX 20/30/40/50 系列**，AMD 显卡不在支持列表里。

1. 到 https://github.com/tylertms/Stela/releases 下载 `stela.exe`
2. 准备 U 盘：在线安装 **8GB**，离线安装 **32GB**（会被清空）
3. 双击 `stela.exe` → 选 U 盘和安装器 → 从 U 盘启动（BIOS 里 Secure Boot 必须关）
4. 起不来时：`stela.exe log --output log.txt`，拿日志去提 Issue

**必须先接受的代价**：Wi-Fi / 蓝牙 / 音频**目前都没有驱动**；性能有明显损失；项目仍在开发中，官方说"可能仍然无法启动"。台式机成功率比笔记本高（笔记本独显常走 Optimus）。

## 第一阶段 · 检测 + 做启动盘（在 Windows 上做）

### 1.1 准备

- 一台 Windows 10/11 电脑
- 一个 **≥8GB 的闲置 U 盘**（里面东西会被清空，别用存着资料的盘）
- 目标电脑能进 BIOS（HP 是开机按 **F10**，联想 F2，戴尔 F2，华硕 F2/Del）

### 1.2 跑工具

下载 `MacPlan.exe`，双击。会出现六步向导：

| 步骤 | 你要做的 | 会看到什么 |
|---|---|---|
| 第 1 步 | 选你的 U 盘 | 列出所有 USB 磁盘和容量，选编号 |
| 第 2 步 | 决定要不要预置 Wi-Fi | 选 `y` 会读本机保存的 Wi-Fi 并写进 EFI |
| 第 3 步 | 什么都不用做 | 自动扫描 CPU / 显卡 / 网卡 / 硬盘 |
| 第 4 步 | 看结论 | ✅ 推荐某个 macOS 版本；❌ 直接劝退并说明原因 |
| 第 5 步 | 等 | 自动生成 EFI + 下载恢复镜像（几分钟，看网速） |
| 第 6 步 | 等 | 写入 U 盘 + 自动校验 |

**成功的标志**：最后打印「✅ 启动盘做好了」，并且校验通过。

**如果失败**，按提示处理，常见三种：

- `容量不足` → 换 ≥8GB 的盘
- `不是 FAT32` → 让工具格式化（要输入大写的 `YES`）
- `OpenCore.efi 体积异常` → EFI 生成失败，重跑第 5 步

> 关于 Wi-Fi：预置后恢复环境一进去就能联网，**但密码是明文写在 EFI 里的**。
> 装完按 3.5 节把它清掉。

## 第二阶段 · BIOS 设置 + 从 U 盘启动（在目标电脑上做）

这是最容易劝退的一步，其实只有 4 个开关。

### 2.1 进 BIOS

1. 关机（不是重启）
2. 插上做好的 U 盘
3. 按电源键，**立刻连按 F10**（HP）/ F2（联想、戴尔、华硕）
4. 进到蓝底或黑白菜单就是 BIOS；如果直接进了 Windows，说明按晚了，重来

### 2.2 只改这四项

| 菜单项 | 设成 | 找不到怎么办 |
|---|---|---|
| Boot Mode / Boot Order | **UEFI**（不要 Legacy/CSM） | 在 Boot 标签下 |
| Secure Boot | **Disabled** | Security → Secure Boot |
| Fast Boot | **Disabled** | Boot → Fast Boot |
| Virtualization (VT-x / SVM) | **Enabled** | Advanced → System Options |

改完按 **F10 保存并退出**（HP 是 F10，联想 F10，戴尔 F10，华硕 F10）。

### 2.3 选 U 盘启动

1. 再开机，**连按 F9**（HP 的启动菜单键；联想 F12，戴尔 F12，华硕 Esc）
2. 列表里选带 `USB` / `UEFI` / 你的 U 盘品牌的那一项
3. 屏幕会变成黑底白字，出现 OpenCore 菜单

> **如果列表里只有 Windows、没有 U 盘**：回 BIOS 确认 Secure Boot 真的关了；
> 换一个 USB 口（优先蓝色 3.0 口，别过 Hub）；还不行就把 U 盘重新做一遍。

### 2.4 OpenCore 菜单怎么操作

- 看到的第一屏可能**只有一项** → **按空格键**，隐藏项会展开
- 会出现三项：`Windows`、一个橙色齿轮 `___U___(dmg)`、`Reset NVRAM`
- **橙色齿轮就是 macOS 安装项**，名字乱码是因为中文卷标没有字形，不是坏了
- 用方向键选中它，回车

> 选 `Reset NVRAM` 会清掉启动项，**不要乱点**。只有引导出问题时才用它。

## 第三阶段 · 安装 + 第一次进系统

### 3.1 抹盘（会清空整块硬盘）

1. 进到「macOS 实用工具」窗口，选**磁盘工具**，点「继续」
2. 左上角「显示」→「显示所有设备」
3. 选中**最外层那块硬盘**（不是它下面的分区）
4. 点「抹掉」，填：
   - 名称：`Macintosh HD`
   - 格式：**APFS**
   - 方案：**GUID 分区图**
5. 点「抹掉」，等几秒

### 3.2 安装

1. 关掉磁盘工具，回到菜单，选「重新安装 macOS」
2. 一路「继续 / 同意」，选刚抹的盘
3. 开始装后**会重启 2~3 次**：
   - 每次重启都回到 OpenCore 菜单
   - 每次都选**同一个安装项**（不是 Windows，也不是 Reset NVRAM）
   - **U 盘全程别拔**
4. 装完会进入「设置助理」：选语言、连 Wi-Fi（预置过就自动有）、**先不要登录 iCloud**、创建电脑账户

### 3.3 装完第一件事：把 EFI 搬进硬盘

不做的后果：**拔掉 U 盘就开不了机**。

打开「终端」，逐条执行（`<U盘名>` 换成你的 U 盘名字）：

```bash
diskutil list
sudo diskutil mount disk0s1
sudo cp -R /Volumes/EFI ~/Desktop/EFI-backup          # 先备份
sudo rm -rf /Volumes/EFI/EFI/Microsoft /Volumes/EFI/EFI/Boot
sudo cp -R "/Volumes/<U盘名>/EFI" /Volumes/EFI/
ls /Volumes/EFI/EFI/OC/OpenCore.efi                   # 有输出就对了
```

然后关机、拔 U 盘、开机。**能自己进系统 = 真的装好了。**

### 3.4 体检

```bash
bash scripts/macos_doctor.sh
```

它会告诉你哪一项还没配好（声音、触控板、睡眠、时区、USB 映射）。

### 3.5 清掉 EFI 里的 Wi-Fi 明文

1. 先装 **HeliPort**（`https://github.com/OpenIntelWireless/HeliPort/releases`），放进「应用程序」
2. 在 HeliPort 里连一次 Wi-Fi（**必须先连上，再删**）
3. 挂载 EFI，编辑 `EFI/OC/Kexts/itlwm.kext/Contents/Info.plist`，把 `WiFiConfig` 整段删掉
4. 重启确认还能上网

## 小白 Tips（这些没人会主动告诉你）

### 装应用

- **优先去官网下载，不要用 App Store**。黑苹果的 App Store 依赖 iCloud 与 SMBIOS，很容易登不上或下载失败
- 官网下载时**选 Intel 版**（不是 Apple Silicon / ARM 版）。你这台是 Intel 机器，ARM 版装不上
- 常见软件：Chrome、VS Code、微信、QQ、WPS、IINA（播放器）、Keka（解压）都有 Intel 版
- 装完提示"无法验证开发者"：系统设置 → 隐私与安全性 → 仍要打开

### 系统

- **不要走 OTA 系统更新**（设置里那个"软件更新"）。SSV 校验必然失败，只能用完整安装包重装升级
- **不要用「磁盘工具 → 急救」修系统宗卷**，黑苹果上很容易修到起不来
- 关闭"自动设置时区"（Intel 网卡没有定位，会自动跳到美国时间）
- 睡眠参数建议：`sleep 15 / displaysleep 10`，笔记本关掉 `powernap`、`womp`、`proximitywake`
- 不要装"清理大师""优化工具"这类软件，它们会删系统缓存导致各种怪问题

### 硬件

- **Wi-Fi 用 HeliPort 管**，系统右上角不会出现 Wi-Fi 图标，这是正常的
- **隔空投送 / 接力 / 通用控制 / 随航 用不了**，Intel 网卡没有 AWDL
- **定位、天气、查找我的 用不了**，同理
- **Type-C 只能传数据和充电，不能接显示器**（这台机器没有 DP Alt Mode）
- **读卡器用不了**（Realtek 读卡器 macOS 没驱动）
- 蓝牙耳机能连，但同时连多个蓝牙设备容易断
- 外接 HDMI 有黑屏风险（SMBIOS 与核显代次不完全匹配），试之前先备份

### 数据与救砖

- **那张 U 盘别扔**，它是唯一的救命盘，系统崩了还能从它进恢复环境
- 第一次装完做一次 Time Machine 备份（需要一个移动硬盘）
- 改 `config.plist` 前先复制一份改名 `config.plist.bak`，改坏了能换回来
- 不要随便改 SMBIOS，改完 iCloud / iMessage 要重新登录

### 账号

- 前期**先别登 iCloud**，等声音、触控板、睡眠都正常了再登
- 想用 iMessage / FaceTime，需要完整的"三码"（SN / MLB / UUID），且同一套不能多人共用，容易封
